# Taj Skyview Residences

Production workspace for the Taj Skyview React front end, hosted on Firebase Hosting
with serverless Cloud Functions for lead submissions.

The frontend is a single-page React application deployed to Firebase Hosting. Lead
submissions are handled by Firebase Cloud Functions and stored in Google Sheets.

## Project Layout

```text
.
├── functions/            Firebase Cloud Functions (Node.js/TypeScript)
├── services/             Alternative backend services (for local development)
├── public/               Static assets served by Vite
├── src/                  React application source
├── dist/                 Built React app (generated by npm run build)
├── firebase.json         Firebase configuration
├── index.html            Vite entry point
├── package.json          Frontend build scripts and dependencies
└── vite.config.ts        Vite build configuration
```

## Quick Start

### Development

```bash
npm install
npm run dev                 # Start Vite dev server (localhost:5173)
firebase emulators:start    # Start Firebase emulators (in another terminal)
```

### Production Build & Deploy

```bash
npm install
npm run build              # Build React app to dist/
firebase deploy            # Deploy to Firebase Hosting + Functions
```

## Common Commands

```bash
npm install                # Install dependencies
npm run dev                # Local development
npm run build              # Production build
npm run lint               # Lint code
npm run deploy             # Build + deploy to Firebase
firebase login             # Authenticate with Firebase
firebase deploy --only hosting   # Deploy only frontend
firebase deploy --only functions # Deploy only functions
firebase emulators:start   # Run local Firebase emulator
```

## Architecture

**Frontend:**
- React 19.2 + TypeScript
- Vite 7 for build optimization
- Tailwind CSS + Bootstrap for styling
- React Router for SPA routing
- Hosted at Firebase Hosting root (`/`)

**Backend:**
- Firebase Cloud Functions (Node.js 20)
- Triggers on POST to `/api/lead/submit`
- Authenticates with secret token
- Appends submissions to Google Sheets
- Rate limiting: 5 submissions per IP per hour

**Storage:**
- Google Sheets (single sheet with lead data)
- Service account authentication
- Automated backup to /forms endpoint

## Notes

- Frontend code is in `src/` and `public/`
- Cloud Functions are in `functions/src/`
- Keep deployment config in `firebase.json`
- Services/ contains alternative backends for local development
- Use Firebase Console for monitoring and troubleshooting
